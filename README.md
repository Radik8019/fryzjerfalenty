# Radosław Kostiw — Fryzjer Falenty Nowe · Warszawa

Luksusowa strona atelier (lokalnie).

```bash
npm install
npm run dev
```

Otwórz adres z terminala (zwykle `http://localhost:5173`).

- PL jest domyślny. EN: `/en`
- Motyw jasny/ciemny: ikona w headerze
- Zdjęcia i tekst „O mnie” podmienisz później w `src/i18n` oraz `public/images`
